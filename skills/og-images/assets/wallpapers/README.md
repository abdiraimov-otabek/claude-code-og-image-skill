# Wallpapers

Five bright landscape pictures, generated with an image model in November 2026. They are not photographs. No people,
buildings, text or logos. Resized to 2400 px wide JPEG (1.8 MB in all) to keep this skill light.

Licence: see [LICENSE-wallpapers.md](LICENSE-wallpapers.md). It is separate from the MIT licence of the code.

`index.json` has each picture's hue, mood and horizon.
