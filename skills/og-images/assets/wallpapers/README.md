# Wallpapers

Five bright landscape pictures, generated with an image model in November 2026. They are not photographs. No people,
buildings, text or logos. Resized to 2400 px wide JPEG (1.8 MB in all) to keep this skill light.

Licence (this is an exception to the MIT licence of the code, see ../../LICENSE): made by the skill's author. Free to use as the background of your own link previews, store images and
launch graphics. Not to be resold or redistributed on their own as a wallpaper pack.

`index.json` has each picture's hue, mood and horizon.
